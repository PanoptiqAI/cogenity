CG / MULTI-ACCOUNT MANAGER

The right AI account for every project.

Keep customer, work, and private Claude Code or Codex accounts separate. Pick one when you start, or let Cogenity choose an account based on available capacity.

Install Cogenity View on GitHub

THE PROBLEM

One machine. Accounts that should not mix.

Provider CLIs usually keep one active login. Switching projects can mean signing out, copying auth files, or starting a session with the wrong account. Cogenity gives each account its own profile and starts the selected CLI in your current directory.

  1. 01

    Add your accounts

    Enroll Claude Code and Codex accounts with the picker or CLI.

  2. 02

    Keep them separate

    Credentials, settings, and provider state stay in separate profiles.

  3. 03

    Start in your project

    Choose an account and continue in the project you already opened.

GET STARTED

Install it with Homebrew.

The macOS download is a standalone executable. Install Claude Code 2.1.144 or newer, Codex, or both before you add an account.

01 / Install

$ brew install PanoptiqAI/tap/cogenity

02 / Add accounts

$ cogenity login claude dev@customer-a.example
$ cogenity login claude me@personal.example

03 / Start

$ cogenity
