MULTI-ACCOUNT MANAGER

Use the right account for each project.

Manage separate customer, work, and private accounts in one place. Choose one, and Cogenity starts Claude Code or Codex with it. Then you work as usual.

GET STARTED

01 / Install

$ brew install PanoptiqAI/tap/cogenity

02 / Start

$ cogenity

THE PROBLEM

One machine. Accounts that should not mix.

Your projects use different accounts, but Claude Code and Codex keep one active login. Switching projects means signing out and back in or risking the wrong account. Cogenity keeps each account in a separate profile.

PROJECT ACCOUNTS

Start each project with the account it needs.
